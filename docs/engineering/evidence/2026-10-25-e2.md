## 冻结契约（E2 拥有）

- **应用级 owner：** Run 在 `AgentRunOwner` 自有 SupervisorJob 作用域执行；调用方作用域死亡不取消 Run；用户取消=先 NonCancellable 持久 CANCELLED 再停协程；授权变更清扫只停已终态（FAILED/CANCELLED/INTERRUPTED）的 tracked run，RUNNING/COMPLETED/未启动不动；删除=事务提交后才停协程。
- **原子失效：** 六个授权变更事务（mode/receiver/grant/revoke/credential 替换与清除）同事务将全部 RUNNING Run 落 FAILED/AUTHORIZATION 并释放 slot；permit 按 epoch 绑定，迟到 completeRun 必被拒（RunInvalidated）。
- **会话删除（B0 §8 单事务）：** 校验 generation+owner → 活动Run内联CANCELLED → operation 状态全量可解析（未知=UnsafeSessionContent 整体拒绝，绝不级联删）→ 引用→消息→提案→Run→会话行删除；`commit_operation` 永不触碰，事后迟到 startRun/completeRun/failRun 一律 NotFound。Report 提供 F2 披露数据（取消数/废弃未确认提案/保留四态计数/删除数）。
- **进程恢复：** `recoverProcess` 仅所有权门禁，遗留 RUNNING→INTERRUPTED，零模型/工具调用；新 Run 重验授权（epoch/generation），被中断输入不进入新上下文。
