## 2. 产品与视觉主线

**日常有迹：精密摘要账页，低干扰 Agent 工作区。** 黑白建立信息层级，朱红只强调当前选择、关联和必要关注，不把所有状态都染成红色。笔记与收支是两种内容，允许不同布局；统一的是文字、数字、边界、反馈和对象身份。

首页标题旁“记账/笔记”是手动入口，完整原生能力不依赖 AI；底部胶囊是统一 Agent 入口。主区不模拟真人聊天：完整记录、当前指令、执行状态与简短回执构成内容。Agent 自主处理明确意图，非必要不问；真正缺少关键值时用一个短任务弹窗，不把问题/答案刷进主区。

不新增余额、预算、账户系统、统计中心、全局搜索、附件、Markdown、标签/项目或社交联系人。首页 Note 主题取正文首句/摘要，不新增标题字段，不默认请求模型给整库命名。生成图若加入了绿色徽章、过大的字体/圆角或额外图标，不自动进入规范；精确 token、字段与本审阅器中的几何是可复核候选，生成图用于美术与构图参考。

## 3. D-SYS：可实现的设计系统

### 3.1 色彩与材质

完整 roles 见 Token，不在页面硬编码不同套颜色。主要映射：

| 语义 | 浅色 | 深色 | 规则 |
|---|---|---|---|
| page / surface | `#F7F7F4` | `#121210` | 连续内容底面 |
| content | `#FFFFFF` | `#1D1D1A` | 必要字段/对象，不逐行堆卡片 |
| onSurface | `#171717` | `#F3F3EC` | 正文、金额、核心状态 |
| supporting text | `#5F5F58` | `#BCBCB1` | 不再降低透明度 |
| primary / onPrimary | 墨黑 / 白 | 浅墨白 / 墨黑 | 主动作、选中黑白面 |
| tertiary / onTertiary | `#BD3B2C` / 白 | `#FF9C89` / `#5E1508` | 朱红强调、关联；不单独代表失败 |
| outline | `#74746C` | `#949488` | 必要输入/控件边界 |
| outlineVariant | `#C7C7BD` | `#47473E` | 非必要装饰分隔 |
| error / container | 见完整 scheme | 见完整 scheme | 明确失败文字和恢复动作，不只变红 |

Provider授权与业务执行授权是两件事；配色不承担权限判断。成功以普通墨色图标＋“已保存/已关联”表达，执行中/未知不显示对勾。warning 使用明确文字配对 container；不以固定橙/绿薄字造成低对比。

两主题各含 primary/secondary/tertiary/error、surface 五级与 dim/bright、outline、inverse、scrim、fixed roles。surface 按 tone 定义，不手工按海拔叠主色；dynamic color 默认不覆盖品牌。浅深均可跟随系统；高对比适配提高必要边界与文字角色，仍需真实 Android 验证。

36 组主要色对的静态公式核验见交付验证：普通文字目标 ≥4.5:1，必要非文字边界 ≥3:1。透明层、实际抗锯齿、状态叠加和整页可访问性不能仅由这组结果证明。

### 3.2 排版、空间与形状

- 字体：Android 系统 sans，中文系统字形；不复制专有字体或下载网络字体。数字启用 tabular，保留币种和正负。金额内部语义为 Long 整数分，展示动画不改变输入文本。
- 起点：品牌 28/34sp、首页标题 36/44sp（紧凑 28/36sp）、金额焦点 44/52sp、列表金额 26/32sp、页面 headline 24/32sp、分区 20/28sp、正文 16/24sp、辅助 14/20sp；12/16sp 只用于少量非操作元数据。完整 weight 值见 Token，不在每页另造字号。
- 内容边距 20dp，窄窗口 16dp；节奏 4/8/12/16/20/24/32/40/48dp。正文避免过长行；大屏编辑正文最大可读宽度建议 640dp，剩余空间用于上下文而非拉长每行。
- 形状：动作 6dp、输入/receipt 8dp、dialog 12dp、sheet 20dp；0/4dp 用于规则化结构。只有 Agent 主入口用 full capsule，形成有意义的形状对比。组件内外半径按实际 inset 设计，不在嵌套处机械复制。
- elevation：内容 0、轻动作 1、Dialog/Sheet 6dp 为候选高度；tone/遮挡优先，阴影解释层次，不为每个边界叠宽阴影。所有正式高亮/材质都有实色退路。

### 3.3 图标与 Agent 标识

常规动作采用 [Google Material Symbols Outlined](https://github.com/google/material-design-icons)，固定来源版本及 19 枚 SVG 放在 [icons](f0-c3/icons/)，保留 [Apache-2.0 LICENSE](f0-c3/icons/LICENSE)。预览用这些真实矢量资源；原生实施需导入对应 Vector 资产，不引入 Web 字体。图标24dp，触控面至少48dp，不靠缩小可点面积获得精致感。

Agent 标识为无脸的开口弧形，源于 S1 底栏；无真人头像、打字表情或持续呼吸。首页使用胶囊入口不重复放悬浮角色；其他正常业务页通过同一 App 内 Host 提供弧形入口，可停靠标题栏/左/右、隐藏并恢复。停靠避让 IME、系统栏、保存/恢复和主动作；提供“靠左/靠右/隐藏”非拖动替代。审阅器的停靠控制只演示位置，不证明已实现 Android 拖动/跨进程保留。无系统悬浮窗权限。

### 3.4 Motion System

| 过程 | 候选动态语法 | 降级 / 状态要求 |
|---|---|---|
| 胶囊→Agent | 220–280ms 边界/容器展开，入口与输入焦点连续 | 系统 scale=0 直接展开，首个输入不丢；动画不发请求 |
| 原生页进出 | 160–220ms 短 fade-through / 8–16dp位移 | Back可反向，不阻塞点击；减少动态即时 |
| 金额/保存状态 | 原始输入即时，辅助状态100–160ms短变换 | 不模拟错误中间金额；成功只由持久结果触发 |
| 日期/筛选 | 选中标识120ms效果变化，保持列表锚点 | 不全列表重新入场，不遮挡类型信息 |
| 列表插入/移位 | 可见条目180–220ms placement，typed stable key | 正式事实提交后才插入；回看旧日期不拉回顶部 |
| Note 阅读/编辑 | 同一文本/选择owner，工具栏120ms出入 | 不整块AnimatedContent重建TextField；IME优先 |
| 关联展开 | 200–280ms局部边界/单次引用轨迹 | 只绘可见对象，低性能/大字退为引用列表 |
| 助手停靠 | 可打断 spatial spring，起点 damping .9 / stiffness500 | 不要求弹跳，隐藏/失焦停止绘制 |
| 必要补问 | 120–160ms Dialog效果，不新增问答气泡 | 单个弹窗，回答后继续，不再确认；关闭不重弹 |
| 执行/失败/未知 | 简短状态切换，真实步骤才展示 | 不伪造百分比、推理链或已完成；未知先核查 |
| 主题 | 120ms色彩效果 | 减少动态即时；重要文字始终可读 |

以上是 Record 的编排选择，不冒充 M3 官方固定时长。几何可用可打断 spring，颜色/透明度不 overshoot。整体默认不使用高成本 shader/模糊；RuntimeShader、AGSL、RenderEffect 留独立实验，不作为设计成立的前提。

读取系统/Compose duration scale；自绘循环显式停用，不依赖动画 API 自动覆盖所有效果。应用不活跃、面板隐藏、状态结束停止不必要工作，恢复不补播装饰。触觉仅在有效选择、停靠或持久成功提供一次轻反馈；尊重系统关闭，不逐 token/失败重试/每个数字键强震。

## 4. D-TIME：首页、连续回看、详情与关联

首页 S1 保留标题旁手动入口与底部 Agent 胶囊；行内只显示发生时间/类型、主题、金额。Note 与收支用语义/结构区分，不靠颜色。类型筛选、今天/日期定位、连续分页仍可达；“日期定位”只锚定连续列表，不退成单日页。首页不放虚构余额和统计大盘。

窄屏单列；600dp起按可用空间比较列表/详情，840dp支持列表/详情/上下文组合，角色/系统区域和颜色语义不因窗口变化改名。折叠、旋转、返回保留当前目的地、日期锚点、筛选、滚动、编辑文本/光标与任务。首页“标题旁”在大字体下允许自然换行，不牺牲48dp触控。

详情完整展示字段/正文和关联；点开对端后返回原位置。关联选择每项有独立 checkbox 和“查看”，查看只读且不丢选中，最后统一保存。隐藏关系不进取消集合，提交按端点/关系版本；冲突全批失败，保留选择并要求重读后检查。没有变化直接返回，有变化返回提供继续/放弃。

| 状态 | 展示 / 行为 |
|---|---|
| 初次加载 / 翻页中 | 初次可用静态skeleton或明确加载；翻页保留已有内容，不伪造记录 |
| 空 / 筛选无结果 | 分别给创建入口/清除筛选；读取错误不能当空 |
| 读取/翻页失败 | 已有内容保留，明确重试；不重置锚点 |
| 记录失效 | 提示不可见/已删除，返回来源；不导航模型字符串 |
| 关联保存中 | 锁重复保存和离开；不部分成功 |
| 冲突 / 失败 | 保留本地选择，未写入时不展示已关联 |
| 长文/长金额/大字号 | 主题可截断，详情完整；金额改行不压小，操作可换行 |

## 5. D-FIN：手动记账与草稿

新建/同身份编辑共用输入结构，标题/方向/金额先于发生时间、日常账户、至多一个可选分类与说明。IME优先，不默认建设自定义计算器。金额文本支持合法编辑中态、粘贴、选中、小数点和尾零，展示格式不抢光标。未获授权的多币种/余额/转账不出现。

| 状态 | 用户可见结果 |
|---|---|
| 不合法金额 / 未来发生时间 | 对应字段短提示，可继续编辑，不做整屏问卷 |
| 草稿保留中/失败/已保留 | 与正式交易保存分开；失败停留/保留输入，不冒充已保存交易 |
| 存在D5 | 继续草稿/显式放弃；AI工作区不覆盖或消费D5 |
| Back | 先处理IME；改动可继续编辑、保留草稿离开、显式放弃；保留失败不离开 |
| 保存中 | 主动作状态变为正在保存，重复和离开被拦截 |
| 失败 / CAS冲突 | 全字段保留；查看最新后再处理，不套最新版本盲重试 |
| 回执未知 | 正在核查，不创建第二笔，不显示成功 |
| 持久成功 | 显示简短回执，消费对应草稿后回原上下文/真实记录 |

## 6. D-NOTE：纯文本、自动保存、删除与恢复

既有 Note 默认阅读，新建直接编辑；“项目讨论。”属于正文首句，不是独立标题字段。正文保留中文、空格、换行与符号。阅读与编辑有不同密度，但同一文本/选择状态；完成编辑只离开，不引入第二套保存语义。

| 状态 | 展示 / 处理 |
|---|---|
| 新建空白 | 不创建事实，可直接返回 |
| 停输/写入中 | 尚未保存→正在保存；既有500ms串行保存，不由动画计时替代 |
| 当前输入版本落盘 | 才显示已保存；旧回执不能把新输入标成已保存 |
| 失败 | “保存失败，输入仍保留”，重试/继续；退出需要显式放弃未保存部分 |
| 清空既有正文 | 原记录未改，不隐式删除；继续输入或恢复上次正文 |
| CAS冲突 | 保留本地正文，只读比对最新，不静默替换或自动采用新version |
| 已被删除 | 停止自动保存，旧缓冲不复活对象 |
| 软删除 / 撤销 | 明示隐藏/可恢复；持久成功后返回来源，原生撤销沿服务合同 |
| 专用恢复 | 列表/只读预览/恢复；同身份、发生时间和隐藏关系，不置顶或复制 |

删除/恢复提交中锁重复，失败维持真实状态。原生 Note 的已支持撤销不等于 Agent 已具备所有操作的通用 undo。

## 7. D-AI：自主执行工作区与最小弹窗

统一自然语言输入，没有记账/笔记/问AI模式。主区展示完整业务对象、必要上下文、当前指令和实际结果，不用人格化寒暄/大量问答气泡。点击入口不自动授权/发送；打开、收起、跨页不取消 Run。任务/会话历史仍可读，不因减少主区噪声丢消息。

直接执行的产品目标及完整例子以[升级方案 §13](record2-uiux-upgrade-proposal-20261024.md#13-最新产品变更明确指令直接执行)为准：利用上下文与已约定默认值，非必要不问；只缺会改变业务结果的关键值才补问。弹窗一句问题，通常2–3个相关候选，点选直接补值继续；没有候选时一个短输入。保留原任务/金额等已知值，不要求重述，关闭暂停当前待补充操作，不重弹、不猜值写入。

补问与答案可在任务详情中追溯，不作为聊天气泡刷屏，不保存为普通 Note。当前用户请求授权来源、Run结束/后续主动Run、Operation与历史绑定属于正式执行契约设计；UI不伪造native-confirm receipt，也不引入模型通用commit工具。

| 状态 | 视觉与动作 |
|---|---|
| 无AI/未授权/缺Key | 解释一个阻塞原因，提供设置入口；原生手动可用，不新增第三模式 |
| Running | 简短真实处理状态/停止动作；无假百分比/隐藏推理 |
| 必要补问 | 紧凑Dialog，不出现在主内容流；无第二次确认 |
| 真实Applied | 简短结果＋真实对象/查看/更正；不做独立提案确认页 |
| 失败/预算/断网 | 保留输入，明确未完成/覆盖范围，不自动反复发模型 |
| Interrupted | 历史保留，不自动续跑；可显式重新发起 |
| 撤销授权/取消 | 停止后续外发与迟到写回；已提交事实/已发送远端内容不能假称撤回 |
| 结果未知 | 先核查稳定Operation，不出现成功与再次创建按钮 |
| 版本/代际/目标冲突 | 保留意图并说明未覆盖；不重放旧payload或复活Note |
| D5并存 | 保留原生草稿，不套用为AI输入、不覆盖slot |
| 恢复后的旧任务 | 可读且不可直接执行；新的主动请求重新校验当前事实 |

Answer/导航/澄清/结构化准备仍有真实语义；取消用户可见确认不表示可忽略它们。正式输出编码/执行边界由差异清单接入。删除/恢复/任意SQL等不自动加入Agent能力。

## 8. D-SAFE：授权、历史、备份与恢复

设置按外观、AI、记录/历史、数据/备份分组，使用一致的平面行与值/动作对齐。AI只有无AI/完整AI；缺Key/不可解密/断网/额度不足是状态，不是新模式。Key输入隐藏、禁建议/纠错，不回显到聊天、日志或备份，网络错误不自动清Key。

授权页显示 DeepSeek / `api.deepseek.com`；内部接收方身份与 E0 catalog 及 scope/disclosure 版本保持一致。“主动任务按需发送相关正常可见记录与必要历史，不默认整库上传/后台扫描”与“撤销不能收回已发送内容”清楚可读。首次同意/重新接收方授权保留，这是权限建立，不是每次业务提案确认。

历史展示会话/任务、摘要、时间与Interrupted/待核查等真实状态。删除会话说明：停止Run、移除可见聊天与未执行材料，不删除正式记录；必要固定提交依据继续保留，不保留完整聊天/隐藏推理当核查依据。存在不能安全保留的Pending/未知核查则阻止删除，先核查；具体新直接执行状态同步正式合同。

| 数据保障阶段 | 设计要求 |
|---|---|
| 导出告知 | ZIP未加密、含私人记录/删除状态/隐藏关系/可见历史，不含Key/有效授权；D5按G0协议明确处理 |
| 选择/预检 | 系统SAF选文件；有界校验中，不提前显示已导入 |
| 已验证候选 | 实际来源/数量/范围；“将整体替换当前数据”和明确“替换并恢复/取消” |
| 源字节变化 | 重新校验，不沿用旧候选 |
| 隔离切换/恢复 | 可取消点按G0真实协议，不可中断阶段禁重复和离开，不伪称取消成功 |
| 失败回退 | 展示真实完整旧数据或完整已验证恢复结果，不能把半库当成功 |
| 重开核查 | 完成后才显示已恢复；历史可读，AI需重新授权和配置凭据，旧任务不自动重放 |

整体替换、原生删除等明确的数据决定不被日常Agent“少问”原则取消。恢复格式、资源阈值、加密能力、草稿段方案不由F0图稿定案。

## 9. Accessibility、输入与状态组件

- 正文/占位字/辅助字按实际背景检查；颜色不做唯一状态。触控≥48dp，选项名称短而完整，图标独立动作有名称，装饰不重复朗读。
- 字体1/1.3/2倍，320/390/600/840dp；大字可换行/退单列，金额改行而非压到小字；不锁固定卡片高度。真实Android非线性字体和字形需后续设备验证。
- TalkBack顺序为页面语境→内容→主动作；状态公告简短、不逐token抢焦点；必要Dialog正确聚焦、返回后恢复来源，问题不滚入主区。
- IME、状态栏、导航栏与cutout使用真实insets；输入/光标不被转场重建，关键保存/发送动作可达。Back先收IME，再处理当前编辑/草稿/敏感提交语义。
- 键盘/D-pad可达；拖动助手、时间定位均有可见替代；减少动态停止空间/循环效果，保留文字状态。
- 共享组件覆盖default/pressed/focused/selected/disabled/loading/error，页面另覆盖empty/conflict/unknown/interrupted/revoked/restoring；disabled不是只降alpha，解释文字仍可读。
